# 05 — YBT 系统功能与架构

这一篇回答：这块 FPGA **在整机里干什么**，数据从哪进、从哪出。

---

## 1. 系统拓扑（单元视角）

SSTMC 是多功率单元级联结构。本 FPGA 是 **某一个功率单元的“主控”**：

```
                    光纤 zz
  系统主控(总控) <------------> 本FPGA(单元主控 SSTMC_FPGA)
                                      ^
                                      | 光纤 zc + 三相相位 zc_a/b/c
                                      v
                                 单元从控(另一块板/另一FPGA)
                                      |
                                      +-- 从控侧电流 I1/I2/I3、温度 T1/T2/T3、从控故障

  本板本地：
    AMC1305 ×2  → 直流上下臂电压 UTh / UBh，合成 Uh
    AMC1035 ×5  → 温度 T4～T8
    驱动芯片    → HB 四管 +（设计上）DC 六管
    风扇        → PWM
```

和 Rock 的差别：Rock 自己就是“整机大脑”；YBT 是“肢体上的小脑”——听总控命令、管好本单元开关、把采样和故障送回去，并把部分命令/相位转发给从控。

---

## 2. 本 FPGA 的职责清单

| # | 职责 | 主要代码 |
|---|------|----------|
| 1 | 与系统主控光纤通信：收命令/PWM/参数，发电压电流温度故障 | `ZZ_*` + `TX_Comm` |
| 2 | 与单元从控光纤通信：下发运行命令和参数，回收电流、温度、故障 | `ZC_*` + `TX_Comm` |
| 3 | 把系统下发的 HB 开关变成带死区的四管驱动 | `SqHBPWM` + `PWM_HBbs` |
| 4 | DC 侧：Boost 软启 → 切入工作 PWM，三相变频+均流 | `BS_DC` `BS_PWM` `JLcon` `PHASE_PROC` |
| 5 | 三相相位同步信号送给从控 | `zc_a/b/c` |
| 6 | 直流电压采样、滑动平均、过压滞回 | `AMC1305_*` `P_GZSC` |
| 7 | 五路温度采样、过温延时保护 | `AMC1035_*` `P_GZSC` |
| 8 | 汇总故障位图，总故障则闭锁 PWM | `sig_Cerr(15)` `sig_Bs` |
| 9 | 风扇 PWM | `TrFAN` |
| 10 | LED 指示通信/HB/DC/故障 | `P_Hled` `P_Dled` 及通信进程内 |

## 3. 时钟与节拍

```
CLKIN 50 MHz ──┬── 所有通信、解码、均流、软启状态机、保护计数、LED
               ├── P_CLK20KHZ → sig_clk20KHz  (20 kHz，约 50% 占空)
               ├── P_CLK5HZ   → sig_clk5Hz    (5 Hz，灯/慢逻辑)
               └── sz_pll → sig_clkMHz 120 MHz
                              ├── HB/DC 死区
                              ├── Boost 三角波 PWM
                              ├── DC 工作变频三角波
                              └── AMC1305 电压采样
```

**20 kHz** 是系统心跳：

- 上升沿：组装一帧 `sig_zzdtout` / `sig_zcdtout` 发给对端
- `TX_Comm` 用 `TXclk=sig_clk20KHz` 启动发送
- 均流 PI 在 `sig_zcclk='1'` 期间算一次

50 MHz / 2500 = 20 kHz，高电平 1250 拍 = 25 µs。

上电复位：50 MHz 计 50000 拍 ≈ **1 ms**，`sig_RES` 从 1→0。PLL 在复位期间被按住。

## 4. 控制数据流

### 4.1 下行（系统 → 本单元 → 从控 / 驱动）

```
系统光纤 zz_r
    → TX_Comm 收 54 bit
    → ZZ_Decodeout
         ├ 命令字(10bit，连续5帧相同才生效)
         │    CLR / H闭锁 / H_PWM
         │    D软启 / D闭锁 / D_PWM
         ├ HPwma, HPwmb     → 死区 → FHS1~4
         ├ Idzl             → 均流电流给定
         ├ P15t             → DC 工作周期基础
         └ 复用 16bit 参数  → P16(Kp) P17(Ki) P18 P19 P23(风扇)
                              其中 Pt 整包转发给从控

本单元 → 从控光纤 zc_t
    命令：CLR / 闭锁 / D软启(11010) / 否则闭锁
    数据：sig_Pt（系统参数透传）
    另：zc_a/b/c = DC 工作 PWM 过半周期标志（相位同步）
```

### 4.2 上行（采样/从控 → 系统）

```
从控 zc_r 43 bit
    → 电流 I1/I2/I3、温度 T1/T2/T3、从控故障位、从控总故障 Dzgz

本地 AMC1305 → UTh, UBh, UhO, UdGY
本地 AMC1035 → T4~T8
本地故障 → Cerr[], Dvft[]

ZZ_sc 在 20 kHz 边沿组 51 bit 发给系统：
    [50:46] 本单元总故障编码
    [45:32] Cerr(13:0)
    [31:16] UhO 直流电压
    [15:0]  14 帧时分复用：I1 I2 I3 Dvft UTh UBh T1s T2s T3s T4~T8
```

## 5. 运行模式（命令怎么变成开关）

系统 10 bit 命令拆成高 5 bit（H 桥）和低 5 bit（D 侧），需 **连续 5 帧相同** 才锁存，防光纤误码。

| 码 | 高 5 bit（H） | 低 5 bit（D） |
|----|---------------|---------------|
| `01001` | 清故障 `CLR=1`，H 关 | — |
| `10100` | H 闭锁 | D 闭锁（若在 Dauto，先延迟再关） |
| `11010` | 开 H_PWM | 开 D_PWM（`Dauto=1`） |
| `10011` | — | D 软启请求 `DPwm_new=1`（从控侧） |

本单元自己的 DC 软启不靠 `10011` 直接出 Boost 波，而是：

1. 系统发 `11010` → `sig_Dauto=1`
2. `BS_DC` 状态机：占空比爬升（Boost）→ 短延迟 → `sig_Dpwm=1` 工作 PWM → `sig_Fauto` 从 750 爬到 1500（降频/扩周期）→ 打开从控故障参与总故障的窗口

H 桥开关 **不是本地载波**：系统每帧直接给 `HPwma/HPwmb` 两个 bit，本 FPGA 只加死区后驱动。这很像“远端调制、本地死区”。

DC 工作 PWM **是本地载波**：周期 = `P15t + Fauto - 均流修正`，限幅 750～2000（120 MHz 三角波），三相 120° 错开。

## 6. 故障与闭锁

```
sig_Cerr(15) = 单元总故障
             = (从控总故障 Dzgz AND 已开放 OpenF)
             OR (zc 通信故障 AND OpenF)
             OR zz 通信故障 Cerr(6)
             OR 直流过压 Cerr(10)
             OR 过温 Dvft(7..11) 等

sig_Bs = sig_RES OR sig_Cerr(15)     -- 总闭锁
```

闭锁后：HB 全关、RDY 拉低；DC 软启/工作状态机回到 0。  
清故障：系统发 CLR，多数计数器、故障位复位。

通信故障检测（zz 与 zc 同构）：

- 光纤收线 50000 拍（1 ms @50 MHz）无跳变 → 线路卡死
- `TXFinish` 连续 1 ms 不来 → 组帧失败

## 7. 模块层次（实际就这一层半）

```
SSTMC_FPGA                          -- 顶层，90% 业务
 ├ sz_pll                           -- 50→120 MHz
 ├ TX_Comm          ×2              -- zz / zc 各一
 ├ AMC1305_16bit_Controller
 │    └ RAM_16_2048 ×2              -- 两路电压滑动窗
 └ AMC1035_5CH_Controller           -- 五路温度
```

对照 Rock 的深层次例化树，YBT 是“胖子顶层 + 瘦子外设”。调试时 **断点式阅读顶层 PROCESS 名** 比画层次图更有效。

## 8. 和 Rock 控制思路的迁移

| 概念 | Rock 里 | YBT 里 |
|------|---------|--------|
| 给定来源 | 以太网命令 / ARM 寄存器 | 光纤帧字段 |
| PWM | 本地调制（LLC 频率、Buck 占空比） | HB=远端 bit；DC=本地三角波 |
| 软启 | `SlowLaunchCtrlCore` | `BS_DC` 占空比再切频率 |
| 均流/均压 | 视产品 | 三通道 PI，给定 `Idzl`，Kp=`P16t`，Ki=`P17t` |
| 保护 | 独立 ProtectCore | 位图 + 顶层组合总故障 |
| 采样标定 | 软件/FPGA 定点 | AMC 模块内乘加 /16384 |
