## 一句话先建立心智模型

- **Rock**：整机级 DC 变换器控制平台（以太网、DDR、Cortex-M0、多路 LLC/BuckBoost、复杂保护/录波）。
- **YBT**：级联/固态变压器（SSTMC）**功率单元主控 FPGA**——光纤上下级通信 + H 桥 PWM + 直流侧 PWM/软启/均流 + 电压/温度采样 + 风扇。

YBT 代码量远小于 Rock，但**业务语义更“电力电子单元级”**；把 Rock 里的“PWM / 保护 / 通信 / ADC”经验迁移过来即可，不必先学完整 VHDL 教科书。
