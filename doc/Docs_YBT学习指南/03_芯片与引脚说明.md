# 03 — 芯片与引脚说明

目标：看懂 `SSTMC_FPGA` 每个端口接到什么硬件，以及和 Rock 板级资源的差别。

---

## 1. FPGA 器件

| 项 | 值 | 说明 |
|----|----|------|
| 系列 | Intel / Altera **Cyclone V** | 对照 Rock 的 Xilinx Artix-7 |
| 型号 | **5CEBA2F17C8** | |
| 拆开读 | 5CE = Cyclone V E；BA2 = 逻辑规模档；F17 = FBGA 256；C8 = 速度档 | |
| 结温 | 0～85℃ | `.qsf` `MIN/MAX_CORE_JUNCTION_TEMP` |
| 配置 | Active Serial x4 + **EPCQ16A** | 上电从 Flash 加载 |
| 配置电平 | 3.3 V | |
| I/O | 未用脚弱上拉 | |

资源量远小于 Artix-7 `xc7a50t`，但对本工程（无以太网、无 DDR、无 CPU）足够。

PLL：片内 `sz_pll`，50 MHz → 120 MHz，专供 PWM 三角波与死区计数。

## 2. 顶层端口总表（按功能分组）

来源：`SSTMC_FPGA.vhd` PORT + `SSTMC_FPGA.qsf` `set_location_assignment`。

### 2.1 时钟与指示

| 端口 | 方向 | 引脚 | 说明 |
|------|------|------|------|
| `CLKIN` | IN | N11 | 50 MHz 晶振 |
| `F_LED1` | OUT | T3 | 系统↔单元主控通信指示 |
| `F_LED2` | OUT | T2 | 单元主控↔从控通信指示 |
| `F_LED3` | OUT | R2 | 亮=重故障；闪烁=H-PWM 工作 |
| `F_LED4` | OUT | R1 | D-PWM 工作；并叠通信单次故障 |

上电约 5 s 内 `sig_ledres` 与 5 Hz 相与，灯会有复位闪烁效果（`P_LEDRES`）。

### 2.2 光纤通信（核心互连）

| 端口 | 方向 | 引脚 | 说明 |
|------|------|------|------|
| `zz_r` | IN | T12 | 系统主控 → 本单元，光纤收 |
| `zz_t` | OUT | T13 | 本单元 → 系统主控，光纤发（代码里 `zz_t <= NOT sig_zzFiberT`，**电平取反**） |
| `zc_r` | IN | R11 | 单元从控 → 本单元，光纤收 |
| `zc_t` | OUT | T10 | 本单元 → 单元从控，光纤发（同样取反） |
| `zc_a` | OUT | R9 | A 相同步/载波相位（来自 DC Work PWM `sig_zca`） |
| `zc_b` | OUT | T8 | B 相 |
| `zc_c` | OUT | T7 | C 相 |

命名习惯：

- **zz** = 系统（总）↔ 单元主控（主）
- **zc** = 单元主控（主）↔ 单元从控（从）
- `_r` receive，`_t` transmit
- `zc_a/b/c` 不是光纤数据，是给从控的 **三相 PWM 相位参考**

### 2.3 H 桥（HB）驱动

| 端口 | 方向 | 引脚 | 代码注释 / 作用 |
|------|------|------|-----------------|
| `FHOE_DRV` | OUT | A12 | HB 输出使能；**当前恒 `'0'`** |
| `FHRDY_12` | OUT | A10 | 桥臂 1/2 就绪 |
| `FHRDY_34` | OUT | B11 | 桥臂 3/4 就绪 |
| `FHS1_DRV` | OUT | A8 | PHB_ATop |
| `FHS2_DRV` | OUT | A9 | PHB_ABot |
| `FHS3_DRV` | OUT | A7 | PHB_BTop |
| `FHS4_DRV` | OUT | B7 | PHB_BBot |
| `F_FLT1~4` | IN | A14, A13, A15, B15 | 驱动故障反馈（低有效）；置位逻辑当前被注释 |

互补关系（`PWM_HBbs`，带死区）：

```
FHS1 = HPwma AND HPwmDa          -- 上管，开通推迟
FHS2 = NOT (HPwma OR HPwmDa)     -- 下管，关断推迟
FHS3 / FHS4 对 HPwmb 同样
```

`HPwma/b` 来自系统光纤下发的即时开关命令，不是本地调制波。

### 2.4 直流侧（DC / 低压）驱动

| 端口 | 方向 | 引脚 | 设计意图（注释中的 PWM_DCbs） | 当前实际赋值 |
|------|------|------|-------------------------------|--------------|
| `FLOE_DRV` | OUT | L15 | DC 输出使能 | 恒 `'0'` |
| `FL1S1_DRV` | OUT | F15 | A 相关断/Boost 管 1 | **CLKIN（调试）** |
| `FL1S2_DRV` | OUT | G16 | A 相关断/Boost 管 2 | **20 kHz 时钟** |
| `FL2S1_DRV` | OUT | G15 | B 相 | **HB a 相原始 PWM** |
| `FL2S2_DRV` | OUT | H16 | B 相 | **HB b 相原始 PWM** |
| `FL3S1_DRV` | OUT | J16 | C 相 | **复位信号** |
| `FL3S2_DRV` | OUT | K16 | C 相 | **120 MHz 时钟** |

正式 DC 输出（注释掉的逻辑）：

- 工作模式 `sig_Dpwm=1`：三相半桥，带 200 ns 死区
- 软启 `sig_Dsoft=1`：Boost 交错 PWM（`sig_DBpwm14*` / `sig_DBpwm23*`）

改回功率输出时：恢复 `PWM_DCbs`，删掉顶层那 6 行调试赋值。

### 2.5 电压 ADC（TI AMC1305 类隔离 ΔΣ）

| 端口 | 方向 | 引脚 | 说明 |
|------|------|------|------|
| `UAD1_CLK` | OUT | C16 | 调制时钟 SCLK 通道 1（上桥臂电压） |
| `UAD1_DAT` | IN | B16 | 比特流 DOUT 1 → `sig_UTh` |
| `UAD2_CLK` | OUT | D16 | SCLK 通道 2（下桥臂电压） |
| `UAD2_DAT` | IN | C15 | DOUT 2 → `sig_UBh` |
| 合成 | — | — | `sig_UhO = 滤波后 CH1+CH2`，过压标志 `sig_UdGY` |

模块：`AMC1305_16bit_Controller`，工作在 120 MHz。

### 2.6 温度 ADC（TI AMC1035 类，5 通道）

| 端口 | 方向 | 引脚 | 内部信号 |
|------|------|------|----------|
| `F_T1CLK` / `F_T1OUT` | OUT/IN | E15 / E16 | `sig_T4O` |
| `F_T2CLK` / `F_T2OUT` | OUT/IN | R15 / T15 | `sig_T5O` |
| `F_T3CLK` / `F_T3OUT` | OUT/IN | R14 / T14 | `sig_T6O` |
| `F_T4CLK` / `F_T4OUT` | OUT/IN | A4 / C4 | `sig_T7O` |
| `F_T5CLK` / `F_T5OUT` | OUT/IN | B6 / A5 | `sig_T8O` |

模块：`AMC1035_5CH_Controller`，50 MHz，5 路共用同一 SCLK 波形。  
CH1～3 与 CH4～5 标定系数不同（见第 7 篇）。过温阈值：CH1～3 用 `T1safe*`，CH4～5 用 `T2safe*`。

从控侧还有 T1/T2/T3（`sig_T1O` 等），经 zc 光纤上报后再线性变换为 `sig_T1s` 等，一起送给系统。

### 2.7 风扇

| 端口 | 方向 | 引脚 | 说明 |
|------|------|------|------|
| `FFAN_PWM` | OUT | B3 | 风扇 PWM（低有效比较：计数 ≥ 给定则拉低？代码里 `P23t <= cnt` 则 `'0'`） |
| `FFAN_COM` | OUT | C3 | 风扇公共/使能，运行时 `'1'` |
| `FFAN_FB1` | IN | A3 | 风扇反馈，**当前未参与保护** |

占空比给定：系统参数 `sig_P23t`（光纤下发通道 `"111"`）。

## 3. 与 Rock 板级资源对照

| 资源 | Rock | YBT |
|------|------|-----|
| 主时钟 | PLL 多路 20/50/100/200 M | 50 M 晶振 + 120 M PWM |
| 通信 | RMII 以太网 ×2、UART、SPI、SWD | **光纤比特流 ×2** |
| 采样 | 片内 XADC + 外部模拟 | **隔离 ΔΣ ADC 芯片** |
| 存储 | DDR3（MIG） | 仅片内小 RAM（滑动平均） |
| CPU | Cortex-M0 软核 | 无 |
| PWM | BuckBoost + LLC 高低压 | HB 4 管 + DC 6 管（设计上） |
| 保护输入 | LLC 过流/过压等 | 驱动 FLT ×4 + 过压/过温软件 |
| 人机 | RGB、系统 LED | 4 颗 LED |

YBT 板是**功率单元控制板**，不是整机通讯/录波平台。

---

## 4. 电平与驱动注意

- 光纤收发有一次 **逻辑取反**（`zz_t <= NOT FiberT`）。示波器看脚和看 `FiberT` 内部信号是反相的。
- HB/DC 的 `BOARD_MODEL_NEAR_PULLDOWN_R OPEN` 只影响 IBIS/板级模型，不影响功能。
- PWM 脚在 `.qsf` 未显式设 I/O 标准，默认随 Bank 电压（需对照原理图，常见 3.3 V LVTTL/LVCMOS）。
- `F_FLT*` 按低电平为故障来滤波（`F_FLTx = '0'` 持续 `NumFI` 拍）。

## 5. 建议你对照原理图核对的清单

1. `FHOE_DRV` / `FLOE_DRV` 高有效还是低有效？当前代码恒 0。
2. `FL*` 六路当前是否仍接驱动芯片？若接了，上电会看到 50 MHz/20 kHz/HB 波形，有风险。
3. AMC1305/1035 的 SCLK 频率是否符合芯片手册（本工程分频见第 7 篇）。
4. 光纤头极性、是否需要外部 PHY。
5. 风扇 PWM 极性（高停还是低停）。
