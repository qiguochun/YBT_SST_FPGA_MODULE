# 05 — ZC 从控通信 逐句（小白向）

源文件：`SSTMC_FPGA.vhd` **552～684** 行。

| 行号 | 进程 / 例化 |
|------|-------------|
| 552～574 | `ZC_sc` |
| 576～606 | `ZC_Error` |
| 608～624 | `ZC_COMM` |
| 626～684 | `ZC_Decodeout` |

---

## 本篇目标

本单元主控 ↔ 单元从控：

| 方向 | 内容 |
|------|------|
| 主控→从控（21 bit） | 运行命令 5bit + 参数 `sig_Pt` 16bit |
| 从控→主控（43 bit） | 故障头、三相电流、温度、故障位（分帧标签） |

---

## 1. `ZC_sc`：组下发帧（552～574）

同样在 `sig_zcclk`（=20kHz）上升沿刷新：

```vhdl
IF sig_CLR='1' OR sig_OpenCLR='1' THEN
  sig_zcdtout(20 DOWNTO 16) <= "01001";   -- 清故障
ELSIF sig_Bs='1' THEN
  sig_zcdtout(20 DOWNTO 16) <= "10100";   -- 闭锁
ELSIF sig_DPwm_new='1' THEN
  sig_zcdtout(20 DOWNTO 16) <= "11010";   -- D 相关工作命令
ELSE
  sig_zcdtout(20 DOWNTO 16) <= "10100";   -- 默认闭锁
END IF;
sig_zcdtout(15 DOWNTO 0) <= sig_Pt;       -- 系统参数透传
```

| 点 | 说明 |
|----|------|
| 命令优先级 | 清故障 > 总闭锁 > D新PWM > 默认闭锁 |
| `sig_Pt` | 来自 ZZ 解码的复用参数，原样给从控 |

---

## 2. `ZC_Error`（576～606）

与 ZZ_Error 几乎同结构：

- `zc_r` 卡死 → 故障  
- 长时间无 `sig_zcFinish` → 故障  
- 结果写入 **`sig_Cerr(0)`**（从控通信故障）

复位 / `sig_CLR` / `sig_OpenCLR` 可清。

---

## 3. `ZC_COMM` 例化（608～624）

```vhdl
GENERIC MAP(DELAY=>20, DtinN=>43, DtOUT=>21)
...
zc_t <= NOT sig_zcFiberT;   -- 624 行
```

收 43、发 21，比 ZZ 短。

## 4. `ZC_Decodeout`：解从控上报（626～684）

### 4.1 复位条件

```vhdl
IF sig_RES='1' OR sig_Cerr(0)='1' THEN
  -- 清电流、温度、相关故障位
```

从控通信一故障，本地也清掉从控来的数据，避免用脏电流做均流。

### 4.2 收帧边沿后解析

**重故障头（42～38）：**

```vhdl
CASE sig_zcdtin(42 DOWNTO 38) IS
  WHEN "01101" => sig_Dzgz <= '1';  -- 从控报重故障
  WHEN "10110" => sig_Dzgz <= '0';
END CASE;
```

**电流分时（37～35 标签 + 34～19 数据）：**

```vhdl
WHEN "001" => sig_I1O <= ...;
WHEN "010" => sig_I2O <= ...;
WHEN "011" => sig_I3O <= ...;
```

**温度 / 故障位（18～16 标签）：**

| 标签 | 含义 |
|------|------|
| 001/010/011 | T1/T2/T3 温度 |
| 100 | 多位 `sig_Cerr`、`sig_Dvft` 从控故障映射 |

### 4.3 温度缩放（后续行）

把 `sig_T1O` 等换成较短的 `sig_T1s` 等，塞进 ZZ 上行轮询帧（带宽限制）。

### 4.4 LED2

收帧时翻转，表示主从光纤活着。

---

## 5. 和均流的关系

`sig_I1O/I2O/I3O` → 进入 **`JLcon`**（06 篇）和系统给定 `sig_Idzl` 做 PI → 修正三相频率。

从控通信挂了 → 电流清零 → 均流也停/清零（见 JLcon 条件）。

---

## 6. 小白易错点

1. **ZC 帧比 ZZ 短**，别用同一张位图硬套。  
2. **`sig_Cerr(0)` 既是故障位，又会复位解码进程**。  
3. **电流不是每帧三相齐全**，靠标签分时更新。  
4. 发端默认经常是闭锁命令 `"10100"`，只有条件满足才发工作命令。
