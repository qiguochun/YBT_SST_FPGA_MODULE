## 1. 这块 FPGA 在干什么（一句话）

**SSTMC 功率单元主控**：听系统总控的光纤命令 → 管本单元 H 桥 / 直流侧 PWM → 采电压温度 → 和从控光纤交互 → 有故障就闭锁。

```
系统总控 ←光纤zz→ 本FPGA(SSTMC_FPGA) ←光纤zc→ 单元从控
                      │
                      ├─ HB 四管驱动
                      ├─ DC 软启 / 工作 PWM
                      ├─ 电压 ADC ×2、温度 ADC ×5
                      └─ 风扇、LED
```

## 4. 关键信号（先记住这些名字）

| 信号 | 含义 |
|------|------|
| `CLKIN` | 板子 50 MHz 晶振时钟 |
| `sig_RES` | 上电复位，`'1'`=复位中，约 1ms 后变 `'0'` |
| `sig_clkMHz` | PLL 输出 ≈120 MHz（PWM/采样快时钟） |
| `sig_clk20KHz` | 20 kHz：通信与均流的“心跳” |
| `sig_Bs` | **总闭锁**：复位或总故障时为 1，PWM 应关 |
| `sig_Cerr(15)` | **单元总故障**（多位 OR 出来） |
| `sig_CLR` | 系统下发的“清故障”命令 |
| `zz_*` / `zc_*` | 系统光纤 / 从控光纤相关 |

总闭锁公式（源码约 201～202 行）：

```text
sig_Cerr(15) = 若干故障位的 OR
sig_Bs       = sig_RES OR sig_Cerr(15)
```

## 6. 怎么对照源码读

1. 用编辑器打开 `YBT_FPGA_SSTMC20260817_fan/SSTMC_FPGA.vhd`  
2. 跳到文档写的行号（或下表进程名）  
3. 先看注释分区（`----2.系统-单元主控通迅----`）  
4. 再看进程名（如 `ZZ_Decodeout`）  
5. 文档行号与当前仓库 `SSTMC_FPGA.vhd` 对齐；你本地若改过源码，以进程名为锚点
