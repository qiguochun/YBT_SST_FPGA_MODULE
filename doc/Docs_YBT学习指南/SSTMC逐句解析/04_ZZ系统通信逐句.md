# 04 — ZZ 系统通信 逐句（小白向）

依赖：先读懂 `03_TX_Comm`。

| 行号 | 进程 / 例化 |
|------|-------------|
| 348～390 | `ZZ_sc` |
| 392～422 | `ZZ_Error` |
| 424～439 | `ZZ_COMM` |

## 本篇目标

系统总控 ↔ 本单元主控：

| 方向 | 信号 | 位宽 | 谁做 |
|------|------|------|------|
| 本板→系统 | `sig_zzdtout` → TX_Comm → `zz_t` | 51 bit | `ZZ_sc` 组帧 |
| 系统→本板 | `zz_r` → TX_Comm → `sig_zzdtin` | 54 bit | `ZZ_Decodeout` 解码 |
| 故障监视 | 光纤卡死/超时 | — | `ZZ_Error` |

## 1. `ZZ_sc`：组上行帧（348～390）

### 1.1 检测 20 kHz 上升沿

```vhdl
sig_zzclk_r <= sig_zzclk;
IF (sig_zzclk='1') AND (sig_zzclk_r='0') THEN
  sig_zzclk_edge <= '1';
ELSE
  sig_zzclk_edge <= '0';
END IF;
```

只有边沿那一拍 `edge=1`，整帧数据刷新一次。

### 1.2 固定字段（每次边沿都写）

```vhdl
IF sig_Cerr(15)='1' THEN
  sig_zzdtout(50 DOWNTO 46) <= "01101";  -- 有总故障的命令头
ELSE
  sig_zzdtout(50 DOWNTO 46) <= "10110";  -- 正常
END IF;
sig_zzdtout(45 DOWNTO 32) <= sig_Cerr(13 DOWNTO 0); -- 故障位图低 14 位
sig_zzdtout(31 DOWNTO 16) <= sig_UhO;               -- 直流总电压
```

### 1.3 低 16 位轮询（var_cnt 1～14）

带宽不够一次发完所有量，所以**每帧换一种数据**：

| var_cnt | 低 16 位内容 |
|---------|----------------|
| 1 | `"0001"` + I1 高 12 位 |
| 2 | `"0010"` + I2 |
| 3 | `"0011"` + I3 |
| 4 | `"0100"` + Dvft 低 12 |
| 5～6 | 上/下臂电压 |
| 7～9 | 从控温度缩放 T1s～T3s |
| 10～14 | 本板温度 T4～T8，然后 cnt 回 0 |

前缀 4 位 = **数据类型标签**，系统靠标签知道这是电流还是温度。

## 2. `ZZ_Error`：通信故障（392～422）

两种超时（约 50000×20ns≈**1 ms**？实际是 50M 时钟 50000 拍 ≈ **1 ms**）：

| 检测 | 含义 | 结果 |
|------|------|------|
| `zz_r` 长时间不变 | 光纤电平卡死 | `var_zzRFt=1` |
| `sig_zzFinish` 长时间为 0 | 一直没收成功帧 | `var_zzcommFt=1` |

```vhdl
sig_Cerr(6) <= var_zzRFt OR var_zzcommFt;  -- ZZ 通信故障位
```

`sig_CLR` 或复位可清故障逻辑。

## 4. `ZZ_Decodeout`：解下行命令（441～548）——最重要

### 4.1 收帧完成边沿

```vhdl
sig_zzFinish_r <= sig_zzFinish;
IF Finish 上升沿 THEN sig_zzFinish_edge <= '1';
```

只在**新收完一帧**时解码。

### 4.2 命令字防抖（连续 5 帧相同才生效）

```vhdl
var_DecdC1 := sig_zzdtin(53 DOWNTO 44);  -- 10 bit 命令
IF var_DecdC1 = var_DecdC0 THEN
  IF var_cntC = 5 THEN
    -- 在这里真正改 sig_CLR / sig_HPwm / sig_Dauto ...
  ELSE
    var_cntC := var_cntC + 1;
  END IF;
ELSE
  var_cntC := 0;
  var_DecdC0 := var_DecdC1;   -- 命令变了，重新计数
END IF;
```

**为什么？** 光纤偶发误码时，不会因为一帧脏数据就切换模式。

### 4.3 命令高 5 位：H 桥相关

| 编码 | 动作 |
|------|------|
| `"01001"` | `sig_CLR=1`，`sig_HPwm=0`（清故障） |
| `"10100"` | H 闭锁：`sig_HPwm=0` |
| `"11010"` | H_PWM 使能：`sig_HPwm=1` |

### 4.4 命令低 5 位：D（直流）相关

| 编码 | 动作 |
|------|------|
| `"10011"` | D 软启准备：`sig_DPwm_new=1` |
| `"10100"` | D 闭锁；若正在自动运行可启动延时停机 |
| `"11010"` | D_PWM：`sig_Dauto=1`（进入自动/工作流程） |

另有 `var_Dstop_*`：闭锁命令后**延时**再清 `sig_Dauto`（用常量 `D_AUTO_OFF_DELAY_CNT`），避免瞬间切断。

### 4.5 每帧都更新的实时量（不要求 5 帧）

```vhdl
sig_HPwma <= sig_zzdtin(43);   -- H 桥臂 A 开关命令
sig_HPwmb <= sig_zzdtin(42);   -- H 桥臂 B
sig_Idzl  <= sig_zzdtin(41 DOWNTO 29) & "000";  -- 均流电流给定
sig_P15t  <= "000" & sig_zzdtin(28 DOWNTO 16);  -- DC 周期基础
```

### 4.6 低 16 位参数复用（连续 4 帧相同）

```vhdl
var_Decd2P1 := sig_zzdtin(15 DOWNTO 0);
-- 相同满 4 次后：
sig_Pt <= var_Decd2P0;   -- 整包转发给从控
CASE 高3位 IS
  WHEN "000" => sig_P16t <= ...;  -- Kp
  WHEN "001" => sig_P17t <= ...;  -- Ki
  WHEN "010" => sig_P18t ...
  WHEN "011" => sig_P19t ...
  WHEN "111" => sig_P23t ...;     -- 风扇给定
END CASE;
```

## 5. 下行帧位域速查（54 bit）

```
[53:44] 命令 10bit（要 5 帧一致）
[43]    HPwma
[42]    HPwmb
[41:29] Idzl（后补 000 成 16bit）
[28:16] P15 相关
[15:0]  复用参数（要 4 帧一致）
```

上行 51 bit 见 `ZZ_sc` 与文档 `08_光纤通信帧与命令字.md`。

---

## 6. 小白易错点

1. **命令不是收一帧就改**，要连续相同计数。  
2. **`sig_HPwma/b` 每帧更新**，和命令字防抖策略不同。  
3. **`sig_Cerr(6)` 是 ZZ 通信故障**，会进总故障 OR。  
4. LED1 在收帧时翻转，表示“系统链路还活着”。
