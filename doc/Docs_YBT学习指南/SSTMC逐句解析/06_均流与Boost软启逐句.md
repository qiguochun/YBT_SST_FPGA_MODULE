## 本篇在系统中的位置

```
系统给定 Idzl、Kp(P16)、Ki(P17)
        +
从控电流 I1/I2/I3
        ↓
     JLcon  → CH1_fI / CH2_fI / CH3_fI（频率修正量）
        ↓
  CALC_NEW_MAX（07篇）改三相载波周期

系统 Dauto
        ↓
     BS_DC 软启状态机 → Driveou1, sig_Fauto, sig_Dpwm...
        ↓
     BS_PWM 三角波比较 → Boost 开关波形
```

## 1. `JLcon` 均流（688～772）

### 1.1 什么时候不算

```vhdl
IF (sig_Fauto /= 1500) OR (sig_Bs='1') OR (sig_CLR='1') OR (sig_Dauto='0') THEN
  -- 清零所有积分/输出
```

只有 **DC 自动频率已经爬到 1500**、未闭锁、未清故障、且 `Dauto=1` 时才跑 PI。

### 1.2 多拍状态机（Step）

| Step | 做什么 |
|------|--------|
| 0 | 等 `sig_zcclk='1'`（20k 高电平窗口）算误差 `ek = I - Idzl`，限幅 ±2047 |
| 1 | 积分项：`yk = yk1d + Ki*ek`，限幅 |
| 2～3 | 空拍（给乘法/流水留拍，或历史遗留） |
| 4 | 比例+积分：`uk = Kp*ek + yk/20000`，再 `/64` 得到 `CH*_fI`，限幅 ±500 |
| 5 | 等 `sig_zcclk='0'` 回到 0（每半个 20k 周期算一次） |

人话：**每个 20 kHz 周期，根据三相电流与给定的差，算出三个“频率微调量”。**

电流大的相 → 正误差 → 频率修正，使功率/电流往均衡靠（具体符号与电力电子设计相关）。

## 2. `BS_DC` Boost / 软启状态机（777～836）

（下列 Step 语义按源码结构归纳，读源码时以 CASE 为准。）

典型流程概念：

1. **复位 / 闭锁 / Dauto=0**：退回安全，占空/频率复位  
2. **软启**：`Driveou1`（比较阈值）逐渐加大 → Boost 占空比爬升  
3. **切入工作 PWM**：`sig_Dpwm` 等标志  
4. **升频**：`sig_Fauto` 从较低值爬到 **1500**  
5. **打开故障门控**：`sig_OpenF` 等，允许某些故障参与总故障  

关键输出：

| 信号 | 含义 |
|------|------|
| `Driveou1` | 给 `BS_PWM` 的比较阈值 |
| `sig_Fauto` | 自动频率偏置（到 1500 才允许均流） |
| `sig_Dsoft` | 软启阶段标志 |
| `sig_Dpwm` | DC 工作 PWM 允许类标志 |
| `sig_OpenCLR` / `sig_OpenF` | 清故障/开故障参与的门控 |

## 3. `BS_PWM`（838～878）

时钟：`sig_clkMHz`（120 MHz）。

做法：

1. 三相错相的三角波计数（常量 `BS_MAXCNT` 等相关）  
2. 与 `Driveou1` 比较  
3. 产生 `sig_DBpwm14a/b/c`、`sig_DBpwm23a/b/c`（Boost 原边开关）

这是标准 **载波比较 PWM**，和风扇三角波同一思想，只是更快、三相错开。

---

## 4. 小白易错点

1. **均流不是一直算**：必须 `Fauto=1500` 且 `Dauto=1`。  
2. **`CH*_fI` 单位是“对周期的修正”**，不是安培。  
3. **软启状态机在 50 MHz 域**，三角波在 120 MHz 域，跨时钟靠缓慢变化的 `Driveou1`。  
4. 读 `BS_DC` 时画出 Step 转移图，比死盯每一行更容易懂。
