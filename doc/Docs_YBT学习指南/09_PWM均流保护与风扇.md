# 09 — PWM、均流、保护与风扇

把电力电子相关算法从 VHDL 里抽出来，用 Rock 里已有的 PWM/软启/保护经验对照。

---

## 1. H 桥 PWM（远端调制 + 本地死区）

系统每 50 µs 下发 `HPwma`、`HPwmb` 两个开关命令。本 FPGA **不产生 HB 载波**。

### 死区

120 MHz 计数 `NumHSQ=192` ≈ 1.6 µs。延迟跟随：

```
输入变了 → 等 192 拍 → 输出跟随
```

互补（A 桥臂为例）：

```
上管 FHS1 = HPwma AND HPwmDa     -- 开通晚
下管 FHS2 = NOT(HPwma OR HPwmDa) -- 关断晚
```

这是典型的“延迟开通”死区，避免直通。和 Rock `PwmGenLLC` 里 deadtime 计数同一思想。

### 使能与闭锁

| 条件 | RDY12/34 | 四管 | Dvft(15) |
|------|----------|------|----------|
| 复位 | 0 | 0 | 0 |
| CLR | 1 | 0 | 0 |
| 总闭锁 Bs | 0 | 0 | 0 |
| HPwm=1 | 1 | 互补 PWM | 1 |
| HPwm=0 | 0 | 0 | 0 |

`FHOE_DRV` 恒 0：若驱动芯片需要 OE=1 才能出波，要改硬件或改这行。

## 2. DC Boost 软启 PWM

目的：直流侧先用 **固定 80 kHz、占空比慢慢加大** 的交错 Boost 把母线/变压器励磁起来，再切到变频工作波。

### 载波

`BS_MAXCNT=750`，120 MHz 三角波：

- 从 0 数到 750 再数回 0，周期 1500 拍 → **80 kHz**
- 三相计数器初相不同，形成交错

比较：

```
DBpwm14 = (Driveou1 >= cnt)           -- 一侧
DBpwm23 = (cnt >= MAX - Driveou1)     -- 另一侧
```

`Driveou1` 由 `var_Drive=1000→4900` 线性映射：`Drive*307/4096`。  
1000×307/4096≈75，4900×307/4096≈367，相对峰值 750，占空比大约 10%→49%。

爬升时间：每 64000/50e6 s 加 1，共 3900 步 ≈ **5.0 s**（注释一致）。

### 当前是否出脚？

`PWM_DCbs` 注释掉后，**Boost 波形只存在于内部信号** `sig_DBpwm*`，低压驱动脚被用来送调试时钟。算法仍在跑，可以用 SignalTap / 把内部信号改接到 LED 观察。

## 3. DC 工作 PWM（变频三角波）

软启 Step2 之后 `sig_Dpwm=1`。每相：

```
周期计数峰值 max = P15t + Fauto - fI     限幅 750～2000
半周 half = max/2
cnt 三角 0↔max，cnt>=half 时输出 1
```

频率：

\[
f = \frac{120\,\mathrm{MHz}}{2 \times max}
\]

| max | 频率 |
|-----|------|
| 750 | 80 kHz |
| 1500 | 40 kHz |
| 2000 | 30 kHz |

`Fauto` 从 750 加到 1500（每 200000/50e6=4 ms 加 1，约 3 s），把频率从 80 k 往下拉。  
`P15t` 由系统给定，再叠加均流 `fI`（±500）。

**更新规则：** 只在 `cnt` 到 0 或到 max 时切换 `max/half`，防止周期中途改阈值产生窄脉冲。

三相初值（`PHASE_PROC` 复位）：

```
A: cnt=750, up=0
B: cnt=215, up=1
C: cnt=270, up=0
```

用来错开约 120°（在 max=750 时）。max 变化后相位关系会漂，这是变频开环交错的常见现象。

`zc_a/b/c` = 各相 `cnt >= half`，给从控对齐载波。

死区 `NumDSQ=24` → 200 ns，逻辑已写（`SqDCPWM`），未接到引脚。

## 4. 均流 PI

在 `Fauto=1500` 且 Dauto、未闭锁时，每个 20 kHz 高电平窗口算一次（状态机 Step0～5）。

对每相电流（来自从控）：

```
e  = Imeas - Idzl           ±2047
y += Ki * e                 Ki=P17t，y 限幅 ±6.4e8
u  = Kp * e + y/20000       Kp=P16t
fI = u/64                   ±500
```

`y/20000`：因为心跳是 20 kHz，积分项按采样周期缩放。  
`fI` 去减 `max`：电流高于给定 → max 变小 → 频率升高。是否“均流”成功取决于主电路：频率升高对输出电流的极性要和调试时确认。

Rock 里类似环在 `VirtualResistanceCore` / 电流环，系数往往 Q 格式；这里系数直接是系统下发的整数。

未投入条件（Step 被清 0，fI=0）：

- 软启未完成（Fauto≠1500）
- 闭锁、CLR、Dauto=0

## 5. 保护分层

```
硬件 FLT（暂未接入总故障）
    F_FLT 低电平 3.6 µs 滤波

软件过压
    AMC 滞回 UdGY → 持续 40 ms → Cerr(10)

软件过温
    温度 > ACT 持续 3 s → Dvft(7~11)
    温度 < RES 只清计数器，故障锁存等 CLR

通信
    1 ms 无跳变 / 无 TXFinish → Cerr(6) zz 或 Cerr(0) zc

从控
    Dzgz、从控位图；OpenF 后才进总故障

总闭锁 sig_Bs
    关 HB；DC 状态机回 Idle
```

过温阈值（12 bit 标定后的值，不是 °C 原文）：

| 通道 | 动作 | 恢复 |
|------|------|------|
| T4 T5 T6 | 162 | 142 |
| T7 T8 | 176 | 156 |

`TsafeTimer=60000`，保护进程每 50 µs 看一次 → 60000×50 µs = **3 s**。

CLR 由系统命令发出，同时复位 zz/zc 超时计数、过压过温锁存、器件计数。

## 6. 风扇

`TrFAN`：50 MHz 三角波 0～1000（往返 2000 拍 → 25 kHz）。

```
若 P23t <= cnt 则 PWM=0 否则 1     -- 给定越大，低电平越宽或相反，按极性理解
复位或总故障：PWM=1，计数停在 1000
运行：FFAN_COM=1
```

`P23t` 来自 zz 参数通道 `"111"`，高位补 0 后 16 bit，与 0～1000 比较，有效给定大约就是 0～1000。

风扇反馈保护未启用。

## 7. 和 Rock PWM 模块的对照

| | Rock | YBT HB | YBT DC |
|--|------|--------|--------|
| 载波 | 本地 | 无（bit 命令） | 本地三角波 |
| 频率 | LLC 变频 / Buck 定频 | 随系统 | 30～80 kHz 可变 |
| 软启 | 独立 Core | 无 | Boost 占空比 5 s + 频率爬升 |
| 死区 | 生成器内 | 1.6 µs | 200 ns（未出脚） |
| 均流 | 视拓扑 | 无 | PI 改周期 |
| 使能 | `oDrvOutEn` | RDY + OE 恒 0 | OE 恒 0 |

## 8. 改 PWM 时先动哪里

1. 确认 `FL*` 是否仍为调试口；要出功率先恢复 `PWM_DCbs`。  
2. 改死区只改 `NumHSQ` / `NumDSQ`。  
3. 改 Boost 频率改 `BS_MAXCNT`（必须和 120 MHz 一起算）。  
4. 改工作频率范围改 `CALC_NEW_MAX` 的 750/2000。  
5. 改均流先确认 `Idzl`、`I1O` 的标幺/位权是否一致（从控 16 bit vs 给定左移 3 位）。  
6. 不要在 120 MHz 进程里做除法过多；现有 `/64` `/20000` 已在 50 MHz 均流里。
