# 08 — 光纤通信帧与命令字

本篇把 zz / zc 的 **位域、命令码、故障位** 集中成表，方便对照示波器或改协议。源码：`SSTMC_FPGA.vhd` 分区 2、3 + `TX_Comm.vhd`。

物理层公共参数见第 7 篇：400 ns/bit，固定头尾 + 偶校验。下面只讲 **payload**。

---

## 1. 链路一览

| 链路 | 方向 | 线 | payload 宽 | 节拍 |
|------|------|----|------------|------|
| zz 上行 | 单元主控 → 系统 | `zz_t` | 51 | 20 kHz 组一帧 |
| zz 下行 | 系统 → 单元主控 | `zz_r` | 54 | 对端同节拍 |
| zc 下行 | 单元主控 → 从控 | `zc_t` | 21 | 20 kHz |
| zc 上行 | 从控 → 单元主控 | `zc_r` | 43 | 同节拍 |
| 相位 | 主控 → 从控 | `zc_a/b/c` | 1 bit×3 | 随 DC 工作 PWM，非 TX_Comm |

发送脚均 `NOT` 后出 FPGA。

---

## 2. zz 上行（本板 → 系统）51 bit

`ZZ_sc` 在 `sig_zzclk` 上升沿更新 `sig_zzdtout`。

```
 50        46 45          32 31          16 15           0
+------------+--------------+--------------+--------------+
| 状态5bit   | Cerr[13:0]   | UhO [15:0]   | 复用字 16bit |
+------------+--------------+--------------+--------------+
```

| 字段 | 取值 |
|------|------|
| 状态 | `Cerr(15)=1` → `"01101"`（故障）；否则 `"10110"`（正常） |
| Cerr[13:0] | 见第 4 节 |
| UhO | 直流合成电压（AMC1305 CH1+CH2 平均后） |
| 复用字 | 高 4 bit 通道号，低 12 bit 数据，14 帧一轮 |

### 复用通道（低 16 bit）

| 帧序号 var_cnt | [15:12] | [11:0] 数据 |
|----------------|---------|-------------|
| 1 | 0001 | I1O[15:4] |
| 2 | 0010 | I2O[15:4] |
| 3 | 0011 | I3O[15:4] |
| 4 | 0100 | Dvft[11:0] |
| 5 | 0101 | UTh[15:4] |
| 6 | 0110 | UBh[15:4] |
| 7 | 0111 | T1s（从控温度标定后） |
| 8 | 1000 | T2s |
| 9 | 1001 | T3s |
| 10 | 1010 | T4O（本地温度） |
| 11 | 1011 | T5O |
| 12 | 1100 | T6O |
| 13 | 1101 | T7O |
| 14 | 1110 | T8O，然后计数清 0 |

20 kHz / 14 ≈ **1.43 kHz** 每个模拟量刷新一次（对系统而言）。

## 3. zz 下行（系统 → 本板）54 bit

`ZZ_Decodeout` 在 `zzFinish` 上升沿解析 `sig_zzdtin`。

```
 53     44 43 42 41        29 28        16 15           0
+---------+--+--+------------+------------+--------------+
| 命令10b |Ha|Hb| Idzl 13b   | P15 13b    | 复用参数 16b |
+---------+--+--+------------+------------+--------------+
```

| 字段 | 处理 |
|------|------|
| 命令 [53:44] | 拆成 [9:5] H 命令、[4:0] D 命令；**连续 5 帧相同** 才执行 |
| Ha/Hb [43:42] | 立刻更新 `HPwma/HPwmb`（每帧都更新，无 5 帧滤波） |
| Idzl | `{dtin[41:29], 3'b000}` |
| P15t | `{3'b000, dtin[28:16]}` |
| [15:0] | 连续 4 帧相同后，按 [15:13] 写入对应参数 |

### H 命令 `[53:49]`（即命令高 5 bit）

| 编码 | 动作 |
|------|------|
| `01001` | `CLR=1`，`HPwm=0` 清故障并关 HB |
| `10100` | `CLR=0`，`HPwm=0` HB 闭锁 |
| `11010` | `CLR=0`，`HPwm=1` 允许 HB PWM |
| 其它 | 保持 |

### D 命令 `[48:44]`（命令低 5 bit）

| 编码 | 动作 |
|------|------|
| `10011` | `DPwm_new=1`（转发给从控，偏软启语义） |
| `10100` | `DPwm_new=0`；若正在 Dauto，启动停机延迟后 `Dauto=0` |
| `11010` | `Dauto=1`，`DPwm_new=0`，清除停机完成标志 → 本板 DC 软启/工作 |
| 其它 | 保持 |

停机延迟：`D_AUTO_OFF_DELAY_CNT=10000` 拍 @50 MHz = 200 µs。延迟期间不再响应新的 `10011/11010`（`Dstop_pending` 挡住）。

### 参数复用 `[15:0]`

| [15:13] | 写入 | 用途 |
|---------|------|------|
| 000 | P16t | 均流 Kp |
| 001 | P17t | 均流 Ki |
| 010 | P18t | 预留/其它（顶层未参与均流） |
| 011 | P19t | 预留 |
| 111 | P23t | 风扇 PWM 给定 |

`sig_Pt` 同时保存最近一次锁定的 16 bit 整包，**原样转发到 zc 下行**。

## 4. 故障位图 `sig_Cerr` / `sig_Dvft`

### Cerr

| bit | 来源 | 含义（据代码） |
|-----|------|----------------|
| 0 | `ZC_Error` | 从控光纤卡死或 1 ms 无完成 |
| 1～4 | 从控帧 `通道100` | 从控上报故障 |
| 5 | 强制 0 | — |
| 6 | `ZZ_Error` | 系统光纤卡死或 1 ms 无完成 |
| 7～9 | 从控 | 从控上报 |
| 10 | `P_GZSC` | 直流过压确认 |
| 11 | 从控 | 从控上报 |
| 12 | （风扇，注释掉） | 未用 |
| 13,14 | 强制 0 | — |
| 15 | 组合逻辑 | **单元总故障**（见下） |

总故障：

```
Cerr(15) = (Dzgz & OpenF) | (Cerr(0) & OpenF)
         | Cerr(6) | Cerr(10)
         | Dvft(0)|Dvft(1)|Dvft(2)|Dvft(3)
         | Dvft(7)|Dvft(8)|Dvft(9)|Dvft(10)|Dvft(11)
```

`OpenF=0` 时忽略从控总故障和 zc 通信故障。

### Dvft

| bit | 来源 | 含义 |
|-----|------|------|
| 0～3 | `Dv_Ft`（赋值注释） | 本应是 F_FLT1～4 |
| 4～6 | 从控通道 100 | 从控装置标志 |
| 7～9 | 本地 T4/T5/T6 过温 | T1 阈值组 |
| 10～11 | 本地 T7/T8 过温 | T2 阈值组 |
| 12 | （DC 工作标志，在注释的 PWM_DCbs） | 当前不置位 |
| 13,14 | 强制 0 | — |
| 15 | `PWM_HBbs` | HB 正在输出（给 LED3 用，也进不进总故障？**不进** Cerr15 表达式） |

## 5. zc 下行（本板 → 从控）21 bit

```
 20        16 15           0
+------------+--------------+
| 命令 5bit  | Pt [15:0]    |
+------------+--------------+
```

| 条件（优先级从高到低） | 命令 5 bit |
|------------------------|------------|
| CLR 或 OpenCLR | `01001` 清故障 |
| 总闭锁 Bs | `10100` |
| DPwm_new=1 | `11010` |
| 其它 | `10100` 闭锁 |

`OpenCLR` 只在 Fauto 刚到 1500 的那 1 s 窗口为 1，用来给从控清一次故障再 `OpenF`。

## 6. zc 上行（从控 → 本板）43 bit

```
 42     38 37  35 34              19 18  16 15           0
+---------+------+------------------+------+--------------+
| 状态5b  | I通道 | 电流 16b         | T通道 | 温度或故障   |
+---------+------+------------------+------+--------------+
```

| 字段 | 含义 |
|------|------|
| [42:38] | `01101` → Dzgz=1；`10110` → Dzgz=0 |
| [37:35] | 001/010/011 → 把 [34:19] 写入 I1/I2/I3 |
| [18:16] | 001/010/011 → [15:0] 为 T1/T2/T3 |
| [18:16]=100 | [15:0] 拆故障：见下 |

通道 100 时：

```
Cerr(4:1)  <= dtin(4:1)
Cerr(9:7)  <= dtin(9:7)
Cerr(11)   <= dtin(11)
Dvft(6:4)  <= dtin(14:12)
```

从控温度再标定：

```
Ts = (TO * 225 - 18118) / 16384    -- 12 bit，上报系统
```

## 7. 命令码记忆

两边复用同一组 5 bit 语义（与系统约定）：

| 码 | 口语 |
|----|------|
| `01001` | 清故障 |
| `10100` | 闭锁 |
| `11010` | PWM/运行 |
| `10011` | 软启（D 侧） |
| `01101` | 故障状态（上报） |
| `10110` | 正常状态（上报） |

改协议时：**TX_Comm 头尾不要动**（对端 FPGA 必须一致）；只改 payload 位宽要同时改 GENERIC 和组帧/解码。

## 8. 对照 Rock 以太网命令

Rock：`EthCmdAnalysisCore` 解析 UDP 载荷，寄存器空间大、可扩展。  
YBT：固定短帧 + 时分复用，**带宽极小、实时性高**（50 µs 一帧量级），适合功率单元闭环，不适合传波形录波。
