## 命令 5 bit

| 码 | 含义 |
|----|------|
| `01001` | 清故障 CLR |
| `10100` | 闭锁 |
| `11010` | 运行 / PWM |
| `10011` | D 软启（转发从控） |
| `01101` | 上报：故障 |
| `10110` | 上报：正常 |

H/D 命令需 **连续 5 帧相同** 才生效；`HPwma/b` 每帧立即更新。

## PWM 公式

```
HB 死区 = 192 / 120M = 1.6 µs
DC 死区 = 24  / 120M = 200 ns      （逻辑有，脚未接）
Boost   f = 120M / (2*750) = 80 kHz
工作    f = 120M / (2 * max)
max     = clip(P15t + Fauto - fI, 750, 2000)   → 80 kHz ~ 30 kHz
Fauto   软启 750 → 1500
```

**现状：** `FL1S1~FL3S2` 被接到 CLK/20k/HB/复位/120M 做调试；`PWM_DCbs` 已注释。

## 均流（Fauto=1500 且 Dauto）

```
e  = Ix - Idzl
y += P17 * e
u  = P16 * e + y/20000
fI = sat(u/64, ±500)     去减 max
```

## 总故障

```
Bs = RES | Cerr(15)
Cerr(15) = (Dzgz|Cerr0)&OpenF | Cerr6(zz) | Cerr10(过压) | Dvft(0..3,7..11)
OpenF 在软启结束后约 1 s 才置 1
```

过压：AMC 滞回后持续 40 ms。过温：超阈值 3 s。FLT 置位代码已注释。

---

## VHDL 三句话

1. `&` = 拼接，与要用 `AND`  
2. `SIGNAL <=` 进程结束才更新；`VARIABLE :=` 立刻  
3. `CONV_INTEGER` / `CONV_STD_LOGIC_VECTOR(n, w)` 做定点
